# Security Policy

## Supported versions

Security fixes are considered for the current `main` branch. Older commits and forks are not maintained as separate supported releases.

## Report a vulnerability

Please report vulnerabilities privately. If GitHub's **Report a vulnerability** option is available on this repository's **Security** tab, use it to open a private advisory. Otherwise, contact the maintainer [@joshadi15](https://github.com/joshadi15) privately through an available contact method on their GitHub profile. If neither private channel is available, request a private reporting channel without including exploit details. Do not post vulnerability details in a public issue or discussion.

Include a concise description, affected component, reproduction steps, expected impact, and a safe proof of concept if possible. Do not include real user prompts, uploaded files, or credentials.

The maintainer will assess reports and coordinate a fix and disclosure with the reporter. No fixed response or release timeline is promised. Please allow time for a fix before public disclosure.

## Areas to check

Relevant reports include unsafe handling of uploaded files, prompt or browser storage exposure, unexpected network requests, and problems involving the optional connection to local Ollama.
